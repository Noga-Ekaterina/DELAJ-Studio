# DELAI Studio

Портфолио-сайт анимационной студии DELAI. Проект показывает направление студии, кейсы для детской и взрослой аудитории, информацию о команде, идеях, вакансиях, контактах и часто задаваемых вопросах.

## О проекте

Сайт построен как интерактивное портфолио с плавной прокруткой, анимациями, showreel-видео и отдельными страницами проектов. Контент хранится в JSON-файлах внутри `public/Assets`, поэтому тексты, проекты, вакансии и футеры можно обновлять без изменения компонентов.

## Моя роль

Проект был принят мной на доработку: разработка велась не с нуля, а на базе уже существующего кода.

На момент передачи в проекте были проблемы с прокруткой, не работал выбор языков, тексты были зашиты прямо в компоненты, отсутствовали страницы проектов, не было анимаций ховеров и не работала форма отклика. В рамках доработки я привела эти части в рабочее состояние, вынесла контент в JSON-файлы, добавила динамические страницы проектов и реализовала серверный рендеринг.

## Возможности

- две языковые версии: русский и английский;
- главная страница с секциями студии, проектов, карьеры, контактов, FAQ и идей;
- разделение проектов на направления `kids` и `adults`;
- динамические страницы проектов с медиа-контентом из папок `public/Assets/Projects`;
- страницы вакансий с формой отклика;
- SEO-метаданные и `alternates` для локализованных страниц;
- плавная прокрутка, модальные окна, Lottie-анимации и адаптивные версии showreel-видео.

## Структура

```text
src/
  app/                  маршруты, layouts, API route для формы
  components/           UI-компоненты, секции, модальные окна и футеры
  store/                MobX-хранилища для общих данных и карьеры
  utils/                утилиты для загрузки данных, скролла и навигации
public/
  Assets/
    Projects/           проекты и медиа для портфолио
    Slides/             JSON-контент секций сайта
    Animations/         Lottie-анимации
    Videos/             showreel-видео
  fonts/                локальные шрифты
```

## Переменные окружения

Для отправки формы в Telegram используются переменные:

```env
TG_BOT_TOKEN=your_bot_token
CHAT_ID=your_chat_id
```

Файл с локальными переменными можно хранить в `.env.local`.

## Контент

Основные данные сайта находятся в `public/Assets`:

- `Slides/About/text.json` - секция о студии;
- `Slides/Animations/text.json` - тексты для лендингов kids/adults;
- `Slides/Contacts/text.json` - контакты;
- `Slides/FAQ/data.json` - вопросы и ответы;
- `Slides/Ideas/text.json` - секция идей;
- `Slides/Vacancy/data.json` - список вакансий;
- `Slides/Vacancy/form.json` - поля формы отклика;
- `Projects/data.json` - список проектов;
- `Footers.json` - данные футеров.

## Примечание

Проект находится на стадии заполнения контента.

В последних коммитах реализован SSR, но в Vercel есть ограничение, из-за которого проект не задеплоился.

Проект использует ISR (`revalidate = 120`) для страниц главной, проектов и вакансий. При деплое важно проверить доступность файлов из `public/Assets` и корректность переменных окружения для формы.
